# LP Fast Motors

Landing page otimizada para captação de leads e conversão para o método Fast Motors.

## 🚀 Tecnologias

- **Frontend:** React + TypeScript + Tailwind CSS
- **Backend/DB:** Supabase (PostgreSQL + Auth + RLS)
- **Componentes:** Shadcn UI
- **Análises:** Sistema interno de métricas

## 📖 Documentação Adicional

- [Guia de Banco de Dados, Leads e Métricas](./README_DATABASE.md) - Detalhes sobre o funcionamento da captação de leads e rastreamento de eventos.

## 🛠️ Como rodar o projeto

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Configure o `.env` com suas credenciais do Supabase
4. Inicie o servidor de desenvolvimento: `npm run dev`
